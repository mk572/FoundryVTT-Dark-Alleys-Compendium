# 13-cld-cleric (pending an owner, not shipped)

This pack is **not DATP content** — it's a separate third-party product
(abbreviated "13ClD"/"13ClDS"/"13CDS" on the 13th Age SRD) that ended up
bundled in this module's original 2020 release alongside the real Dark
Alleys content, without ever actually belonging to Dark Alleys or to this
project's owner. Confirmed unrelated during the 2026-09-12 SRD content
comparison pass (see this project's `CLAUDE.md`).

**Removed from `module.json`/`packs/` on 2026-09-14** and kept here only
as a reference copy (extracted via `@foundryvtt/foundryvtt-cli`'s
`extractPack`) while the project owner looks for whoever actually owns
this content, so it can be handed off or published under its own name
instead of continuing to ship inside a module it was never really part
of. Not intended to go back into `module.json` under this project.
